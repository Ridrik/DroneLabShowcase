About

DroneLab is a C++ based 3D simulator and visualizer tool for drone guidance, navigation, and control (GNC). It supports live and replay sessions with extensible user control and visualization tools. Some of its core features include:

  • GNC core: rigid-body dynamics with RK4 integration, discrete EKF for state estimation, and cascade PID controllers
  • User friendly configurable editor for controllers, drone parameters, sensors, estimators, rules, environments, waypoints and more
  • Waypoint following and return-to-launch modes, with more flight modes planned
  • Simulation control: pause, slow or speed up even on a live session
  • Interactive features: mouse hover and add waypoints dynamically, or toggle sensors On/Off
  • Visual outputs: plots, telemetry panels, minimap, 3D trajectory trails, ghost drone estimates, covariance ellipsoids, and more
  • Replayer: Each live session is recorded and saved, allowing the user to load and visualize any past run as if it was live.
  • (Experimental) ROS2 Interface and MAVLink support: send simulation sensor data and receive external actuator commands, allowing for testing with external flight controllers in SITL/HITL.

This tool is currently in development. If you are interested in previews, demonstrations, or collaboration, please get in touch (contact details at the end).
